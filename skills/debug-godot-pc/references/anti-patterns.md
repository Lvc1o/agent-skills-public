# Anti-padrões
- Corrigir no chute sem reproduzir.
- Embrulhar o erro em `if x != null` sem achar por que é null.
- Mexer em vários arquivos ao mesmo tempo.
- Rodar no projeto original com os saves do dono.
- Fechar o jogo dele à força para "testar rápido".
- Deixar `print` de debug no código.
- Declarar "resolvido" sem prova observada.
